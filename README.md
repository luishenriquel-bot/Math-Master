# Math-Master

MathMaster — Guia de Frações e Sólidos Geométricos
Este README explica como determinar frações equivalentes, como fazer adição e subtração de frações, e dá uma introdução aos sólidos geométricos e à relação de Euler (V - E + F = 2). Também indica as perguntas adicionadas ao jogo.

Frações equivalentes
Uma fração equivalente representa a mesma porção do todo, mesmo tendo numerador e denominador diferentes.

Como encontrar frações equivalentes:

Multiplique (ou divida) o numerador e o denominador pelo mesmo número diferente de zero.
Exemplo: para encontrar uma fração equivalente a 2/3 com denominador 12: 2/3 × 4/4 = 8/12.
Dicas:

Para verificar equivalência, simplifique ambas as frações ao menor termo; se forem iguais, são equivalentes.
Para transformar uma fração para um denominador específico, calcule o fator multiplicativo: fator = novoDenominador / denominadorAtual.
Adição de frações
Passos para somar frações:

Se os denominadores forem iguais, some apenas os numeradores e mantenha o denominador.
Ex.: 3/8 + 2/8 = (3+2)/8 = 5/8.
Se os denominadores forem diferentes, encontre o m.m.c. (mínimo múltiplo comum) dos denominadores e transforme cada fração para esse denominador.
Ex.: 1/2 + 1/4 → m.m.c. de 2 e 4 é 4. 1/2 = 2/4, então 2/4 + 1/4 = 3/4.
Simplifique o resultado, quando possível.
Subtração de frações
A subtração segue as mesmas regras da adição:

Se os denominadores forem iguais, subtraia os numeradores: 7/10 - 3/10 = 4/10 → simplificar para 2/5.
Se forem diferentes, leve ao mesmo denominador (m.m.c.) e então subtraia os numeradores.
Dízima periódica
Uma dízima periódica é um número decimal em que uma ou mais casas decimais se repetem infinitamente em um padrão.

Exemplos:

0,333... = 1/3
0,121212... = 4/33
0,666... = 2/3
Ela pode ser:

Simples: quando o período começa logo após a vírgula. Ex.: 0,333...
Composta: quando existe uma parte não periódica antes do período. Ex.: 0,1666...
Uma forma de reconhecer é observar que, após certo ponto, o mesmo bloco de números se repete infinitamente.

Sólidos Geométricos (noções básicas)
Sólidos geométricos são objetos tridimensionais com vértices (V), arestas (E) e faces (F). Exemplos comuns:

Cubo: V=8, E=12, F=6
Tetraedro regular: V=4, E=6, F=4
Octaedro: V=6, E=12, F=8
Dodecaedro regular: V=20, E=30, F=12
Relação de Euler
Para muitos sólidos convexos (como os poliedros regulares), vale a fórmula de Euler:

V - E + F = 2

Exemplos:

Cubo: 8 - 12 + 6 = 2
Tetraedro: 4 - 6 + 4 = 2
Dodecaedro: 20 - 30 + 12 = 2
