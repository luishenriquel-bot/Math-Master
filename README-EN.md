# Math Master Evolution

Math Master Evolution is an educational browser game designed to help students practice mathematics in a fun way, with challenges, rewards, and level progression.

## Game rules

1. The player starts with 5 lives.
2. Each correctly answered question gives XP.
3. XP helps the player level up.
4. An incorrect answer in a regular lesson costs one life.
5. In practice mode, the player can train without losing lives.
6. Completing a practice session restores one life.
7. The daily challenge can be played once per day.
8. Completing the daily challenge earns gems, XP, and extra lives.
9. The shop sells a refill of 5 lives for 50 gems.

## Local profile and progress

On first launch, choose a name or nickname to create a profile on this device. No online account, email, password, or external service is used. Your profile and progress are saved in this browser using `localStorage`.

The game includes lessons, a practice mode, a daily challenge, hints, achievements, statistics, sound controls, and optional Portuguese speech synthesis. Profile and progress can be exported to a JSON file and imported later from the statistics screen. Those files are generated or selected by the player; sample progress files are not part of the app.

## Run on Replit

Click **Run** and open the Replit Preview. The project serves the existing HTML, CSS, and JavaScript on `0.0.0.0:5000` using Python's standard library; no package installation or secrets are needed.

Sound effects and the geometric-solids illustration are included locally. Some other geometric-solid illustrations still use external image URLs.
